method overriding
------------------
- when child class writes a method which is already declared in parent
- every java class is a child class of Object class

super
-------
- to invoke parent class constructor
- call to super must be first statement in constructor
- if parent class has no-arg constructor, compiler can write super()
  inside child class constructor.
- when parent class has a parameterized constructor, we have to write 
  super() with paramaters explicitely inside child class constructor
  
final
------
- variable (restrict changing value of a variable)
  final variable value cann't be changed. it becomes constant
- method (restrict method overriding)
  final method cann't be overriden in child class
- class (restrict inheritance)
  a final class cann't be inherited

String
------
-STring objects can be created in 2 ways

1. String s1 = new String("Sachin"); // new
2. String s2 = "sachin"; // string literal

- when we create string object using 'new', everytime a new object 
is created in 'heap'.

- when we create string object using literal, first it will be checked 
in SCP wheather a string object with same content is there in SCP or not?

- if no, it creates a new object in scp.
- if yes, it will not create a new object rather it will return the address
of existing object

equals()  compares content of 2 string objects
==        compares address of 2 string objects

Exception Handling
------------------
Error - Compile time problems
exception - runtime 

Terminologies
-------------
try - it contains a block of statements where exception might occur
catch - it contains exception handling code
finally - it contains a block of statements which needs to be executed
		  in any situation (important statements)
throw - to throw exceptions explicitly (User Defined Exceptions)
throws - to declare exceptions, to delegate the exception

Type Of Exceptions
------------------
1. unchecked Exception
2. Checked Exceptions

- the exceptions which are checked at Compile Time but
occurs at runtime are checked exceptions
- the exception classes which are not child class of "RunTimeException"
are checked

- the exceptions which are checked at runtime and occurs at 
runtime are unchecked exceptions.
- the exception classes which are child class of "RunTimeException"
are unchecked
