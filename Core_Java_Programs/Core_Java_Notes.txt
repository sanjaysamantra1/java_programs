JDK , JRE & JVM
===============
JDK : a software kit that contains tools to develop, compile, and run Java programs
	  JDK = JRE + Tools (compiler, debugger, etc.)
JRE : an environment that provides libraries and JVM to run Java programs
	  JVM + Libraries
JVM : a virtual machine that executes Java bytecode on any operating system

Bytecode : platform-independent intermediate code generated by the Java compiler




JVM architecture
================
-JVM architecture is divided into three primary subsystems: 
	1. Class Loader Subsystem 
			a. Loading: Loads the class bytecode
			b. Linking: Checks that bytecode is structurally valid, Allocates memory for class-level static fields and initializes them to default values
			c. Executes all static initializers and assigns the actual defined values to static variables
	2. Runtime Data Areas (Memory): 
			a. Shared between threads: 
					Heap: Stores objects and arrays created at runtime
					Method Area:Stores class-level structures, such as class metadata, runtime constant pools, and method-related information.
			b. Per-thread areas:
					Java Stack: Each thread has its own stack containing frames for method calls.
					PC (Program Counter) Registers: Keeps track of the memory address of the current JVM instruction being executed for that specific thread.
					Native Method Stack: Holds execution state and instruction tracking for methods written in non-Java languages (like C or C++) accessed via JNI.
	3. Execution : 
			a. Interpreter: Reads and executes bytecode instructions
			b. JIT (Just-In-Time) Compiler : Compiles frequently executed code into native machine code at runtime. This can improve performance by reducing the need to interpret those sections repeatedly
			c. Garbage Collector (GC): Reclaims heap memory occupied by objects that are no longer reachable

Steps to Download Java Software, Write a Program, and Execute
=============================================================
1. Visit https://www.oracle.com/java/technologies/downloads
2. Download the JDK for your operating system (Windows/Mac/Linux)
3. Install the JDK by running the installer
4. Verify installation using:  java -version  and  javac -version
5. Open any text editor (Notepad / VS Code / IntelliJ)
6. Write your Java program and save it with .java extension (Example: Hello.java)
7. Open Command Prompt / Terminal
8. Navigate to the folder where the Java file is saved
9. Compile the program using:  javac Hello.java
10. Run the program using:     java Hello

Typecasting
===========
-Typecasting is the process of converting a value from one data type to another.
-Typecasting does not change the original variable; it produces a converted value used in the assignment or expression
-Java supports two main types of primitive typecasting:
	1. Implicit typecasting (Widening) — Java converts a smaller-range type to a larger-range type automatically.
	2. Explicit typecasting (Narrowing) — The programmer specifies the conversion, which may result in data loss.

Common widening conversions:
byte → short → int → long → float → double
char → int → long → float → double

Wrapper Classes
===============
-Wrapper classes are classes in Java that represent primitive data types as objects.
-Java has 8 primitive data types, and each has a corresponding wrapper class.
-Wrapper classes : Byte, Short, Integer, Long, Float, Double, Character, Boolean

Wrapper classes are useful when:
1. Working with collections: Java collections such as ArrayList store objects, not primitive values directly.
2. Converting strings: Methods such as Integer.parseInt() help convert user input into numeric values.
3. Representing missing values: An Integer reference can be null, whereas an int cannot be null.
4. Using utility methods: Wrapper classes provide methods and constants for working with primitive values.


Autoboxing and Unboxing
========================
-Autoboxing is the automatic conversion of a primitive value into its corresponding wrapper object. ex: int to Integer
-Unboxing is the automatic conversion of a wrapper object into its corresponding primitive value. ex: Integer to int

Note: A wrapper reference can be null. Trying to unbox it causes a NullPointerException. To avoid this, check for null before unboxing.

Integer number = null;
if (number != null) {
    int value = number;
    System.out.println(value);
} else {
    System.out.println("Number is not available");
}

Operator precedence	
====================
-When an expression contains multiple operators, precedence determines which operators bind more tightly. Associativity determines grouping when operators have the same precedence.

	int result = 10 + 5 * 2;  
	System.out.println(result);  // 20
-Multiplication has higher precedence than addition

-Subtraction groups from left to right:
  int result = 20 - 5 - 3;  // 12


== vs .equals()
==================
-For primitives, == compares values. For reference types, == checks whether both references refer to the same object, not whether two different objects have equal contents.
-Use .equals() to compare String contents. For your own classes, implement equals() if you need meaningful content-based equality.

Array Copy
==========
1. Reference Copy — NOT a Real Copy : Copy the reference, not the array
	int[] a = {10, 20, 30};
	int[] b = a;  // Both variables point to the same array

2. Shallow Copy - clone()
   int[] a = {10, 20, 30};
   int[] b = a.clone();
   Are the objects inside the copied array also new? - No

3. Deep Copy -  deep copy creates a new array & New objects inside the array
   Are the objects inside the copied array also new? - Yes
